# Static assets

The UI references two files from this directory:

| File               | Used by                                  |
|--------------------|------------------------------------------|
| `novadc_icac.png`  | Home page and reports page header logo   |
| `novadc_icac.ico`  | Navbar icon and the browser tab favicon  |

They are unit branding and are not distributed with the source. Drop
them in here after cloning. The application runs without them — the
images simply render as broken — so a missing logo will never stop you
documenting a scene.
